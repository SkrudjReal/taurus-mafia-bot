# Taurus Mafia Bot — modern aiogram 3 rewrite

Современная архитектура Telegram-бота Taurus Mafia под `uv`, Python 3.12+ и актуальный `aiogram 3.x`.
Функционал приведён к исходному старому `bot.py` и дополнен новой рулеткой по командам `рулетка` / `/spin`.

## Что внутри

- `src/taurus_mafia_bot/main.py` — точка запуска, `Bot`, `Dispatcher`, dependency injection.
- `src/taurus_mafia_bot/config.py` — настройки из `.env` через `pydantic-settings`.
- `src/taurus_mafia_bot/db.py` — async SQLite слой на `aiosqlite` + миграции.
- `src/taurus_mafia_bot/services/` — бизнес-логика:
  - `economy.py` — пользователи, профиль, баланс, переводы, конвертация, админы;
  - `shop.py` — динамический каталог бонусов магазина;
  - `missions.py` — задания из `data/missions.json`, отчёты, подтверждение и награды;
  - `roulette.py` — рулетка, список призов, шансы, гарантированные NFT и выдача выигрышей.
- `src/taurus_mafia_bot/routers/` — aiogram 3 routers:
  - `start.py` — `/start`, `/help`, `/info`, `/tw`, `/top`, `/convert`, профиль;
  - `shop.py` — магазин, покупка бонусов, мои бонусы, заявки на использование, управление бонусами;
  - `roulette.py` — `рулетка`, `/spin`, inline-прокрут;
  - `admin.py` — `/tm`, `/tc`, `/admin`, `/apanel`, `/users`, `/user`, `/rass`, `-прокрут`, игровые награды;
  - `missions.py` — `Мои задания`, отчёты, админ-подтверждение, импорт/экспорт, `/reset_missions`.
- `tests/` — тесты экономики, конвертации, магазина, заданий и рулетки.

## Команды и функции

### Пользовательские

- `/start` — регистрация/обновление профиля и главное меню.
- `/help` или `хелп` — меню помощи.
- `/info` — ID текущего чата/топика.
- `/tw` — баланс.
- `/top`, `/topt`, `топ` или `топ тауронов` — топ пользователей по `T` и сумма всех тауронов.
- `/convert` — конвертация `TC` в `T` по текущему курсу.
- `Профиль` — карточка пользователя + инвентарь.
- `Магазин` — каталог бонусов из админ-панели.
- `Мои бонусы` — инвентарь с кнопками заявки на использование.
- `Мои задания` — активные задания и отправка отчёта.
- `рулетка` или `/spin` — показать рулетку, список призов и кнопку прокрута за `5 T`.
- `/муу @user/ID сумма` или `/муу сумма` реплаем — перевод `T`.
- `/буи @user/ID сумма` или `/буи сумма` реплаем — перевод `TC`.

### Админские

- `/tm @user/ID сумма` или `/tm сумма` реплаем — выдать/списать `T`.
- `/tc @user/ID сумма` или `/tc сумма` реплаем — выдать/списать `TC`.
- `/apanel` — админ-панель.
- `/admin @user/ID` — переключить админку пользователю, доступно владельцу.
- `/users` — список пользователей.
- `/user @user/ID` — карточка пользователя.
- `/rass` — текстовая рассылка всем зарегистрированным пользователям.
- `/reset_missions` — вернуть выполненные задания в pending.
- `-прокрут @user/ID` или `-прокрут` реплаем — обнулить прокрутки рулетки выбранному игроку.
- `выдать т победителям 10` / `выдать тс участникам 5` — начисление наград по реплаю на сообщение игры с числовыми ID.
- Управление бонусами в `/apanel`: список, добавление, удаление.
- Подтверждение/отклонение отчётов по заданиям и заявок на использование бонусов через inline-кнопки.

## Магазин и бонусы

- Магазин берёт бонусы из таблицы `shop_bonus_types`.
- Добавление бонуса: `/apanel` → `Управление бонусами` → `Добавить бонус` → отправить `Название | Описание | Цена`.
- Покупка списывает `T` и добавляет бонус в `user_prizes`.
- Покупка и использование бонусов отправляют уведомления в дефолтный лог-топик `LOG_CHAT_ID`/`LOG_THREAD_ID` и/или приватно по `ADMIN_IDS`.

## Рулетка

- Команды: `рулетка`, `/spin`.
- Команды показывают список призов в expandable blockquote и кнопку `Крутить рулетку — 5 T`.
- Обычные призы: `АТ-1`, `АТ-2`, `Снять варн`, `Тауроны`, `Преф-2`, `Покупка режима`, `Брак`, `Развод`, `VIP в Ирисе`, `Зазывала VIP`.
- Специальные призы: `Telegram Premium` — 1%, `ТГ NFT` — 2%.
- Каждый 50-й прокрут игрока гарантированно выдаёт `ТГ NFT`; каждый 100-й прокрут игрока также попадает в эту гарантию.
- Приз `Тауроны` начисляет пользователю 3 `T`, остальные призы попадают в `Мои бонусы`.

## Настройка

```bash
cd ~/projects/mainstream/taurus-mafia-bot
cp .env.example .env
nano .env
```

Заполнить минимум:

```dotenv
BOT_TOKEN=токен_бота
OWNER_ID=telegram_id_главного_админа
ADMIN_IDS=telegram_id_главного_админа,telegram_id_ещё_админа
LOG_CHAT_ID=-1003333957923
LOG_THREAD_ID=2215
ROULETTE_LOG_CHAT_ID=-1003333957923
ROULETTE_LOG_THREAD_ID=18657
```

По умолчанию значения захардкожены так же, как в legacy `bot.py`: обычные логи идут в `https://t.me/c/3333957923/2215`, а рулетка отдельно в `https://t.me/c/3333957923/18657`.
`LOG_CHAT_ID`/`LOG_THREAD_ID` можно намеренно очистить в `.env`, тогда бот будет пытаться слать обычные уведомления только в приватные чаты админов из `ADMIN_IDS`.

## Запуск через uv

```bash
uv sync
uv run taurus-mafia-bot
```

Альтернативно:

```bash
uv run python -m taurus_mafia_bot
```

## Тесты

```bash
uv run pytest -q
uv run python -m compileall -q src bot.py main.py
```

## Старые файлы

`bot.py` и `main.py` оставлены как тонкие совместимые entrypoint-обёртки, которые запускают новый пакетный код из `src/taurus_mafia_bot`.

Старый монолит на aiogram 2.x больше не является рабочей архитектурой проекта, но пользовательский функционал портируется в текущую модульную архитектуру.
